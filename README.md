## What is Graligen?

<sup>_**grålig**_ means _**grayish**_ in Danish</sup>  
<sup>in the spirit of being Gralig's namesake, I merged it with _**igen**_ - which means _**again**_ in Danish - forming _**graligen**_ (_**gralig**_ + _**igen**_)</sup>

> [!NOTE]
> This is an attempt to revitalize the [deprecated Gralig CSS library](https://github.com/erenesto/gralig).
>
> I make no promises about my being able to fully commit to doing so, but Gralig is a project that I really respect and enjoy, and I think it would be a shame to lose it to the sands of time.

Graligen is a modest, grayish CSS library. It can be starting point for your CSS development. It provides a set of small modules, including flexbox-based grid and dark mode. All components are built using pure CSS - the library contains no JavaScript.
